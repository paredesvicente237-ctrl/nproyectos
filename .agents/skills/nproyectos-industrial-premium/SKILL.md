# N Proyectos Industrial Premium

Use this skill for visual, UX, or conversion changes to the public N Proyectos website. Keep the existing orange, graphite, and white identity anchored to the current logo; choose precision and confidence over generic industrial/SaaS decoration.

## Non-negotiable context

- Speak to industrial buyers in clear Spanish and make technical capabilities easy to assess.
- Use only verified company facts, real authorized project evidence, and actual product specifications. Never invent customers, testimonials, certifications, capacity, delivery times, or project outcomes.
- Preserve existing quote, WhatsApp, assistant, analytics, privacy, and product-download behavior unless the request explicitly changes it. Do not modify the intranet or Cotizador VA business logic.
- Keep SEO metadata and crawlability intact. Do not publish or deploy without explicit authorization.
- Prefer local assets and fonts already in the project. Optimize image size and framing; clearly identify illustrative imagery when it is not an N Proyectos project.

## Design direction

- Brand palette: clean white, logo orange, deep graphite, and restrained technical grays. Use orange as a deliberate signal, not a blanket fill.
- Compose with clear editorial hierarchy, strong alignment, controlled negative space, and a few purposeful image-led moments. Avoid repetitive cards, gratuitous gradients/shadows, and decorative numbering without meaning.
- Make the main commercial action obvious and contextual. Keep paths to a quote short and preserve truthful confirmation states.
- Use responsive layouts, readable type scales, visible focus, semantic controls, accessible contrast, keyboard support, reduced-motion preferences, and mobile safe areas.

## Required working loop

1. Inspect the live public site and the relevant local components before editing. Capture representative desktop and mobile states when a browser is available; record concrete issues, not taste-only claims.
2. Identify the highest-impact one or two problems and choose a restrained design direction specific to industrial engineering and the current brand.
3. Implement only the scoped improvements, reusing existing product and contact flows.
4. Review the result at narrow mobile, tablet, and desktop widths. Capture screenshots, compare against the initial state, and fix visible hierarchy, contrast, wrapping, overlap, or spacing problems.
5. Run the applicable lint, type, tests, and production build. Review the touched UI with the installed `web-design-guidelines` skill, fetching its current source rules before each audit.
6. Report what changed, what was actually verified, remaining evidence/assets needed from the company, and whether anything is still local/Preview rather than Production.

## When evidence is missing

Use a clearly labeled capability/process reference only where appropriate. Do not imply it is a completed N Proyectos job. Ask for authorized real photos, specifications, or project details when they are needed to substantiate a claim.
